# Matriz de herramientas de IA para el TIF

| Herramienta | Uso principal | Momento de uso | Riesgo | Prioridad |
|---|---|---|---|---|
| ChatGPT | Tutoría metodológica, planificación, revisión y documentación | Durante todo el proyecto | Confundir planificación con implementación | Alta |
| GitHub Copilot en VSCode | Implementación guiada, refactorización y apoyo técnico | Después de definir tareas | Cambios excesivos o no revisados | Alta |
| Copilot instructions | Reglas generales para asistentes en el repositorio | Inicio | Instrucciones genéricas o demasiado amplias | Alta |
| Prompt files | Tareas reutilizables y trazables | Inicio / auditoría | Prompts no mantenidos | Alta |
| Agente Auditor | Diagnóstico técnico y metodológico | Antes del backlog | Proponer refactorizaciones prematuras | Alta |
| Agente Implementador Prudente | Ejecución de issues pequeños | Durante implementación | Tocar más archivos de los necesarios | Alta |
| Agente Revisor Metodológico | Validación académica y técnica | Durante análisis y redacción | Crítica no priorizada | Alta |
| Skills | Automatizar tareas repetibles | Después de detectar repetición | Sobreingeniería | Media |
| MCP GitHub | Gestionar issues, PRs y trazabilidad | Después del backlog | Complejidad operativa | Media |
| Instagit / knowledge bases | Apoyo complementario | Después de validar calidad | Fuente desactualizada o no normativa | Baja-media |
| OpenAI Cookbook | Patrones de prompts y agentes | Diseño de flujos | Sofisticación innecesaria | Media |
| Documentación oficial GitHub | Fuente normativa para Copilot y GitHub | Siempre | Ninguno relevante | Alta |
| Documentación oficial VSCode | Configuración del entorno | Siempre | Ninguno relevante | Alta |
| Documentación scikit-learn / pandas | Implementación analítica | Fase de datos y modelos | Aplicar recetas sin validar supuestos | Alta |
